# Vibe Check

A light security audit you run **before** you ship a vibe-coded app. A deterministic
engine does the grunt work and an AI agent reasons over what's left — and every finding
is a real request the engine replays and re-confirms, so there are no hallucinated bugs.

### Download
**→ https://chickenswaffle.github.io/vibe-check/** (or grab the latest `.dmg` from
[Releases](https://github.com/chickenswaffle/vibe-check/releases/latest)).

macOS, universal (Intel + Apple Silicon). First launch: right-click the app → Open
(it isn't notarized yet).

This repo hosts the download page and release builds. The source is private.
