GOOD TO KNOW

A few things
before you dive in.

What is available to download right now?

The public v0.1.0 release is a terminal-backed macOS app, distributed as an Intel/x86_64 DMG and through the Homebrew cask. The interactive desktop visuals on this page preview newer work in development.

Does the preview scan my site?

No. This page uses synthetic sample data to demonstrate the workflow. It sends no scan requests and asks for no target, credentials or API key.

Do I need an AI API key?

No. The deterministic engine can run without AI. Optional OpenRouter review involves a separate provider request; review its data handling and spending settings before enabling it.

Does a clean scan mean my app is secure?

A scan covers selected checks within a bounded scope. Unassessed behavior, application-specific business logic and organizational controls still need review. It is not a security guarantee or compliance certification.
